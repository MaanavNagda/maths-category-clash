MATHS CATEGORY CLASH — PROJECT PLAN
===================================
A Jeopardy-style quiz game for a MathsSoc club session. Native Linux desktop app,
100% local/offline at runtime, trademark-neutral branding (user-renameable).

STACK
-----
- Python 3 + PySide6 (Qt WebEngine) — two native windows sharing one in-process
  game controller via Qt WebChannel.
- UI written in HTML/CSS/JS inside each window; KaTeX vendored locally for LaTeX.
- No CDN, no external requests (request interceptor blocks non-local URLs).
- unittest (stdlib) for tests — no extra test deps.

BRANDING (defaults, all renameable in host settings, persisted to config.json)
----------------------------------------------------------------------------
- Game title:        "Maths Category Clash"
- Daily Double:      "All In"        (authentic wager, not double-points)
- Final Jeopardy:    "Grand Finale"  (wagers + 300s timer)
- Round 2 board:     "Bonus Board"   (hidden, Ctrl+Shift+R)
- Tile values:       points (100/200/300/400), not dollars
- Visual identity:   distinct minimalist dark theme — NOT the Jeopardy! blue grid.

GAME RULES (custom, differ from TV Jeopardy)
--------------------------------------------
- 5 teams (host-configurable 2–8) of students, whiteboard "speed flash":
  all teams solve simultaneously; ranked by finishing order.
- Up to 3 attempts per team within the time limit (host-judged, not enforced in app).
- No point penalties for wrong answers (except All In / Grand Finale wagers).
- Plain answers — no "what is...?" format.
- Timers by board row: regular board 30s/45s/60s/2min, bonus board 2min/5min.
  Autostart, no pause. Host may end a question early. Timeout = tile dead, 0 pts.
- Scoring: 1st correct team = 100% of value, each next = −10% (100/90/80/70/60…),
  rounded to int. Teams that don't solve = 0.
- All In tile: host picks answering team + wager (cap = max(team score,
  highest tile value on that board)). Correct = +wager, wrong = −wager.
  Uses tile's normal row timer.
- Grand Finale: category shown → host enters each team's wager privately
  (cap = max(0, score)) → clue + 300s timer → host marks each team right/wrong
  → final standings.
- Dual-host workflow: Host A runs screen/timer, Host B judges whiteboards.

TWO WINDOWS
-----------
DISPLAY (projector): logo → rules → 4×4 board (+scoreboard bar) → question +
big countdown → answer → scores → finale → standings. Tiles clickable.
HOST (laptop): setup (team count/names, three markdown uploads — board /
bonus / finale — upload logo, rename labels) → per-question: answer shown
privately, team tiles clicked in finishing order (click again to undo),
End Question / Abort buttons → wager entry for All In & Grand Finale →
shortcut hint printed in footer.

CONTENT
-------
- Questions uploaded at runtime by host (file picker) as THREE separate
  markdown files: regular board (4×4), bonus board (2×2), Grand Finale clue.
  App ships with board/bonus/finale .example.md only — no bundled questions.
- Markdown format: blank-line-separated blocks of Category:/Points:/
  Question:/Answer: (+ optional "All In: yes"; finale adds "Seconds:").
  Clues grouped by Category (column order = first seen), sorted by Points
  (row order). Any positive point values allowed.
- Logo uploaded by host, copied to userdata/ (gitignored). Default: placeholder.
- config.json (gitignored) persists labels + logo path + all three file paths
  + team names — everything reloads automatically next launch.

  bonus board → Grand Finale → standings.
